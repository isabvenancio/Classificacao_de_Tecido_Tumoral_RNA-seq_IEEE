# Classificação de Tecido Tumoral a partir de Expressão Gênica

Projeto Integrador Final do Projeto de Processamento de Dados - Ramo Estudantil IEEE - UEM.

## Objetivo

Classificar amostras de tecido de mama como **tumoral (1)** ou **não tumoral (0)** a partir de dados de expressão gênica, usando redução de dimensionalidade (PCA) e os classificadores k-NN e Regressão Logística, em um notebook reprodutível no Google Colab.

## Dados

Dataset **Gene Expression Profiles of Breast Cancer**, subconjunto **BC-TCGA**: 590 amostras (529 tumorais e 61 normais) com 17.814 genes, provenientes do The Cancer Genome Atlas (TCGA).

- Kaggle: https://www.kaggle.com/datasets/saurabhshahane/gene-expression-profiles-of-breast-cancer?select=BC-TCGA
- Original (Mendeley Data): https://data.mendeley.com/datasets/v3cc2p38hb/1 (DOI 10.17632/v3cc2p38hb.1)

Os dados brutos **não são versionados** neste repositório. Para reproduzir, baixe a pasta BC-TCGA de um dos links acima e siga as instruções do notebook (a serem adicionadas).
